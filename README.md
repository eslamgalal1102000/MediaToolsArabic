# Media Tools Arabic — المرحلة 1

نوع النسخة: **Debug** (غير موقّعة للنشر، صالحة للتثبيت على هاتفك).

## كيف تحصل على الـ APK (بدون تثبيت أي شيء)
1. أنشئ حسابًا على github.com ثم مستودعًا جديدًا (Private يكفي).
2. ارفع **محتويات** هذا المجلد كلها إلى المستودع، مع الانتباه للمجلد المخفي `.github`.
   إن لم يُرفع مع السحب والإفلات: من GitHub اختر Add file ثم Create new file واكتب المسار
   `.github/workflows/build-apk.yml` والصق محتوى الملف.
3. افتح تبويب **Actions** وانتظر انتهاء "Build APK" (عدة دقائق). إن لم يبدأ، اختر Run workflow.
4. افتح التشغيل الناجح ونزّل من Artifacts الملف `MediaToolsArabic-debug-apk` (ملف ZIP بداخله `app-debug.apk`).
5. انقله إلى الهاتف وثبّته (يلزم السماح بالتثبيت من مصادر غير معروفة لتطبيق الملفات).
6. إذا فشل البناء: انسخ آخر سطور سجل الخطأ وأرسلها لي لأصلحها.

## إعادة البناء محليًا
JDK 17 وAndroid Studio (أو Gradle 8.7 وAndroid SDK 34) ثم: `gradle testDebugUnitTest assembleDebug`
الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## المنفَّذ في هذه المرحلة (لم يُبنَ ولم يُجرَّب بعد)
- واجهة عربية RTL داكنة بستة تبويبات.
- **ضغط الصوت إلى حجم مستهدف**: 5/10/15/20/25 MB أو حجم مخصص (الافتراضي 15 MB)، إعادة ترميز فعلية إلى M4A (AAC)، حساب معدل البت، التحقق من الحجم الحقيقي، حتى 4 محاولات، رسالة واضحة إذا كان الهدف مستحيلًا (أقل من 32 kbps)، والملف الأصلي لا يُعدَّل.
- **فيديو أو صوت إلى M4A** بمعدلات 96/128/192/256/320 kbps من ملف على الهاتف.
- اختيار الملف والحفظ عبر Storage Access Framework بدون صلاحيات تخزين شاملة.
- حذف الملفات المؤقتة بعد انتهاء العملية، وتنظيف المتبقي منها عند بدء التطبيق.
- اختبارات وحدة لحسابات معدل البت (5 اختبارات، تعمل ضمن بناء GitHub).

## غير منفَّذ بعد
- تنزيل الروابط، قائمة الانتظار وتحديد 3 مهام، الاستئناف، خيارات Wi-Fi/البيانات، الإشعارات.
- قاعدة البيانات وسجل المهام، مدير الملفات، المشغّل، الإعدادات، بيانات ID3.
- **صيغة MP3**: لا يوجد مُرمّز MP3 في أندرويد. المخطط إضافة LAME (LGPL) عبر NDK. حاليًا الناتج M4A فقط.
- بحث المصادر: YouTube وغيره لن يُضاف إلا بطرق مسموحة؛ نبدأ بالروابط المباشرة.

## اختيارات تقنية
- Media3 Transformer (Apache 2.0، رسمية من Google، محدّثة) للترميز المحلي.
- MB عشري (1,000,000 بايت) في كل الحسابات، مع هامش 2% للحاوية.
- لا إنترنت ولا تتبع ولا صلاحيات في هذه المرحلة.

## ملاحظة عن الاختبار
لم يُشغَّل أي اختبار حتى الآن لأن بيئتي لا تحتوي Android SDK ولا Gradle ولا إنترنت.
الحساب العددي لاختبارات معدل البت تحققت منه بحساب منفصل فقط. أول بناء على GitHub هو أول تجربة حقيقية.
